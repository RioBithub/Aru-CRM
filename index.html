Buat laporan aktivitas

Format fleksibel untuk vendor, klien, rapat, tindak lanjut, atau koordinasi WhatsApp.

01 · Identitas kegiatan

Informasi tambahan sesuai kebutuhan

Contoh: Nomor SPK, nilai penawaran, kendala, SLA, nomor tiket, atau hasil inspeksi.

02 · Lokasi dan metode kerja

◎ Status GPS perangkat

Mengambil posisi terkini...

Check-in GPS tercatat untuk kunjungan lapangan. Laporan WhatsApp/online tidak diklaim sebagai kunjungan fisik.

03 · Foto kegiatan (wajib untuk tatap muka/lapangan)

04 · Bukti pendukung (wajib untuk laporan selesai)

Tatap muka: sertakan foto kegiatan serta bukti operasional. Elektronik/online: wajib bukti komunikasi atau dokumen pendukung. Maksimal 6 lampiran, sekitar 480 KB per file.

Pastikan lampiran hanya memuat informasi kerja yang memang boleh dibagikan. Redaksi chat pribadi bila perlu.

05 · Konfirmasi pihak terkait (opsional)

Bisa ditandatangani vendor, klien, mitra, atau PIC lain. Tidak wajib untuk laporan koordinasi tanpa tatap muka.

Laporan bisa berupa kunjungan, koordinasi jarak jauh, monitoring, atau tindak lanjut. Setelah disimpan, progres dan lampiran WhatsApp selanjutnya dapat ditambahkan melalui Detail → + Perkembangan, tanpa mengubah catatan awal.

Akun langsung aktif. Password sementara wajib diganti saat login pertama. Admin memiliki akses ke seluruh laporan, persetujuan akun, serta manajemen pengguna.

Edit akun pengguna

Perubahan hak akses akan mengakhiri sesi login pengguna. Pegawai yang dijadikan admin wajib mengganti password saat masuk kembali.

Reset password pengguna (opsional)

Kosongkan kedua kolom jika tidak ingin mengubah password. Jika diisi, sesi login akan diputus dan pengguna wajib mengganti password sementara saat masuk kembali.

Ganti password awal

Demi keamanan akun, password sementara wajib diganti sebelum memakai aplikasi.
